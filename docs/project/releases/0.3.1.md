# 0.3.1 范围与验收

0.3.1 承接 0.3.0 后的音频修复、交互反馈及视频作品目录识别与双区预览。原始一期需求的交付关系见 [0.3.0 发布与验收](0.3.0.md)。人工通过候选后再合入并发布，候选、人工结果和正式包分别记录对应提交。[发布流程](../../workflow/release.md)

| 规格 | 本期范围和候选核验 |
| --- | --- |
| [ALB-002](../../specs/official/virtual-albums.md#alb-002-旧版标签收藏评分与封面) | 打开实体来源专辑或已识别作品。核对详情和侧栏的书签同步，收藏专辑在所属来源中靠前。标题下的五星支持半星，竖三点菜单提供零分和清除评分。悬停标签显示红叉。点玻璃加号，输入前缀，用鼠标或方向键选取已有标签，再用 Enter 连续添加，核对焦点回到输入框。点标题左侧封面，核对遮罩与自动、单张及拼图封面。重启核对数据。 |
| [SRCH-003](../../specs/official/search.md#分类结果与标签搜索) | 用 `#` 或 `＃` 添加分类，连续选两项，命中其一即可。关键词、范围和文件／目录筛选仍一起生效。已选标签显示于搜索框右侧，多项以有清楚错位轮廓的卡片层叠。悬停时各卡展开为独立边框的纵向条目，可逐项用灰色叉移除。 |
| [BRW-002／003／004](../../specs/official/browsing.md) · [UI-006](../../specs/official/appearance.md#ui-006-媒体展示切换器) | 文件浏览右侧设置图标打开排序菜单，只有现有准则、方向与恢复原次序。选中列表行保持普通字号，以系统强调色高亮。切换列表、画廊和图标，核对玻璃材质、悬停和选中可辨、焦点及当前媒体。 |
| [LIB-013](../../specs/official/library.md#lib-013-添加重扫和删除媒体源) | 实物触控板左滑展开圆形重扫、删除按钮，点击侧栏或内容区其他位置收起，原点击继续生效。重新展开并分别试重扫与删除后取消。 |
| [LIB-006](../../specs/official/library.md#lib-006-两种视频作品结构) · [PRE-004](../../specs/official/preview.md#pre-004-视频作品的沉浸模式) | 核对完整、简化、普通图片专辑和旧来源重扫。沉浸总览左侧为竖式透明盒，优先采用同目录比例合适的图片，盒下显示视频文件名。右侧照片堆支持触控板翻动。Space 开盒并开始播放，Tab 切换操作区，视频继续播放时可翻图。Mac 可用 ⌘↩ 入场。Esc 逐级返回并停播，图库入口移除焦点框。具体入口见[视频作品索引与预览](../acceptance.md#视频作品索引与预览)。 |
| [PRE-006](../../specs/official/preview.md#pre-006-常见视频格式与本地回退) | 将已合入的[双声道回退修复](https://github.com/AMindFlow/iPreview/pull/83)纳入安装包。在两端双声道设备播放 56 秒 `av-sync-ffv1-flac.mkv`，核对声音、画面、同步、暂停及定位。 |

适用历史需求见 [#59](https://github.com/AMindFlow/iPreview/issues/59)、[#60](https://github.com/AMindFlow/iPreview/issues/60)、[#63](https://github.com/AMindFlow/iPreview/issues/63)、[#65](https://github.com/AMindFlow/iPreview/issues/65) 和 [#75](https://github.com/AMindFlow/iPreview/issues/75)。

用户核验候选 `abf8334aaec3` 后确认其余项目通过，提出将录像带盒下方改为视频文件名。Mac `9f03c5726c3d` 与 Windows `b14eb6555ab0` 实机复验了 `clip.mp4` 及长中文文件名。Windows 同时复验了书签同步、四种封面场景、默认视频控制、快进、Tab 切换和两次 Esc 返回。Windows 构建增加解包启动检查，确认应用能打开隔离资料库并保持运行。正式包来源和校验值见发布附件。[PR #84](https://github.com/AMindFlow/iPreview/pull/84)

Windows 实体触控板、干净机器离线验收和设备现场声画证据继续见 [#75](https://github.com/AMindFlow/iPreview/issues/75) 与 [#63](https://github.com/AMindFlow/iPreview/issues/63)。
