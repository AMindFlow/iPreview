## 实际验证及边界

功能基线的 [CI 44298783579](https://github.com/AMindFlow/iPreview/actions/runs/44298783579) 已通过 macOS ARM64 构建、Windows x64 构建、macOS15 原生启动。PR #48/#49/#50 有当前提交独立审阅、Codex 审阅及 Merge Queue 合入记录。

双端 Computer Use 已检查三种概览与快捷键、最后预览项恢复、侧栏与入口、层级进退、搜索焦点、整窗预览、Windows 文件名复制和视频锁定／15秒控制。安装后原有用户索引可读；13 个基础合成媒体的路径、SHA-256及修改时间保持一致。前序 PR 记录了导入、重启恢复、真实重命名、批量选片／移除、调整排序及离线等对应验收，最新包只复验与修改相关的流程。

最终安装器的构建、双端安装结果、最终提交、下载与哈希以本版本集中物料及 [GitHub Release](https://github.com/AMindFlow/iPreview/releases/tag/v0.1.0) 为准。未获得签名证书：Mac 应用为 ad hoc 签名、未公证；Windows EXE 未做 Authenticode 签名。此状态不表述为已通过官方认证分发。

macOS15 最终视觉、减少动态效果、Windows 高对比与手动关闭透明效果尚未全矩阵人工核验；扬声器输出未完整核验。独立瘦身 PR #27 仍待干净 Windows11 x64 离线验收，不包含在本期已完成项中。

复验操作以[统一验收步骤](../acceptance.md)为准；剩余产品目标见[未完成需求](../backlog.md)。
