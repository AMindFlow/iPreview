# 0.4.0 范围与验收

本版承接 [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3) 的漫画双页、媒体元信息读取和视频作品回归，纳入图片自动播放并修复两处预览反馈。

| 工作包 | 规格与入口 | 候选核验 |
| --- | --- | --- |
| 画廊和视频进度条 | [#105](https://github.com/AMindFlow/iPreview/issues/105) · [PRE-001、PRE-008](../../specs/official/preview.md) | 两端用不同尺寸的带编号大图验证画廊选中联动和 Space 预览。快速按键和长按分别做冷、暖两轮。加载中保留可用画面，坏图显示错误且可继续。普通视频预览和作品沉浸模式点按、拖动进度条，核对旧位置无残留高亮，并检查键盘定位及普通视频锁定。 |
| 漫画双页与自动播放 | PRE-003 · [#106](https://github.com/AMindFlow/iPreview/issues/106) · [#85](https://github.com/AMindFlow/iPreview/issues/85) | 导入六页和七页带编号专辑。启用漫画双页，切换首页单张及配对，前后翻页至边界，检查减少动态设置和退出选择。验证单页、双页自动播放，含开始、暂停、继续、停止、常用和自定义停留时间、手动导航以及末页或离开图片时停止。 |
| 视频元信息读取 | META-001 · [#104](https://github.com/AMindFlow/iPreview/issues/104) | 通过媒体菜单查看实际视频尺寸、时长、标题和作者。分别用带标签、无标签、损坏和离线的样例检查结果。从一条媒体换到另一条时核对结果归属。对比合成文件读取前后哈希。单独音频沿用音频组织的排期。 |
| 本地视频作品 | [LIB-006](../../specs/official/library.md#lib-006-两种视频作品结构) · [#62](https://github.com/AMindFlow/iPreview/issues/62) | 按[作品验收步骤](../acceptance.md#视频作品索引与预览)复验作品根目录、父目录、完整和简化结构，以及旧库重扫、离线重连、媒体 ID 和文件快照。沉浸总览以已索引的官方样张作为影碟盒封面，无可用样张时从主视频取帧。自动刮削待用户调研后另定。 |

用户确认 META-002 待后续确定格式、字段与恢复方案，本版元信息功能为只读。

## 工作包依赖

预览修复和图片阅读在独立 worktree 实施，合流时复验共用的预览导航。元信息读取和 LIB-006 封面与本地回归可独立推进。合流顺序为预览修复、图片阅读、视频元信息、作品封面、版本号与登记；构建和自测通过后，给出同一候选提交的双端人工核验入口。

独立测试判定依据由 Antigravity CLI 的 Gemini 4 Hydrogen High 准备。Windows 实机核验使用 Windows App 的 Win11 Dev。两端使用隔离资料库与合成样例，正式发布遵循[发布流程](../../workflow/release.md)。
