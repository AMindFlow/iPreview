## 原项目简介
piscosmic 原本实现了浏览器可访问的图片管理站，可导入本地文件夹，形成索引后在浏览器内可实现类似 Quicklook 的浏览方式，并支持创建虚拟专辑，跨文件夹浏览。
后因跨平台需求，用 electron 技术栈实现了双端可用(macOS15/win11) 。
附带的一个功能点是多工作区，支持用户在不同工作区保存不同的文件夹/专辑管理数据。

## 项目重启目标
### 管理对象
扩大管理对象类型范围，支持：
- 图片(原项目支持的所有类型)
- 视频(常见格式)
- 音频(常见格式)

### 管理体系
#### 图片
图片在导入时可自动识别如下模式：
- **creator-album**：
```
creator A/
├── album A/
│   └── *.jpg / *.png
├── album B/
      └── *.jpg / *.png
```
- **multi-creator-album**:
```
multi creators dir/
├ creator A/
    ├── album A/
    │   └── *.jpg / *.png
    └── album B/
        └── *.jpg / *.png
└ creator B/
    ├── album A/
    │   └── *.jpg / *.png
    └── album C/
        └── *.jpg / *.png
```
#### 视频
参考 https://github.com/peach-mitao/peach 的组织方案。
但需要支持两种种特定的层级关系：
```
作品 ABC-123
├── 视频
│   └── 高视频.mp4
├── 官方样张
│   └── 来自刮削源的图片
└── 附加写真集
    ├── 写真集 A
    │   ├── 封面
    │   └── 图片 1...N
    └── 写真集 B
        ├── 封面
        └── 图片 1...N
```
及简化版：
```
作品 ABC-123
├── 视频.mp4
├── 官方样张.jpg
└── 附加写真集
   └── 图片 1...N
```

### 功能模块及细节
功能的具体模块和逻辑细节参照老项目，主要是实现在应用内通过 `space` 和方向键快速预览各媒体文件。
需要新增的功能为：
#### 搜索增强
若已有则保留，若未实现则新增：
- 支持按各级目录或文件名模糊搜索
- 支持选择搜索模式，精确/模糊、是否搜索目录、是否搜索文件等

#### 专辑信息管理
支持从专辑文件中(主要是视频和音频)提取元信息，例如清晰度、作者等，并支持从应用内修改并反应到实际文件。

### 美术效果
#### 图片预览
##### 常规
- 主显图片占据最主体的位置，显示比例自适应
- 主显图片四个方向可见相邻图片，层叠并略模糊
- 其余部分遮罩/模糊/暗淡，让用户的注意力集中在查看的图片上
##### 漫画模式
- 模仿书页，分屏左右各显示一张
- 可即时调整首页单双页码，避免翻页画面对不上
- 仿真实翻页效果

#### 视频专辑预览
- 影碟+图册模拟，直接预览专辑而非专辑内部内容时，展示若干影碟和若干图册，通过方向键选择要进入的对象，enter 进入
- 预览媒体文件时，esc 返回上一层，退回最初进入的层级时再 esc 则结束预览

#### 音频预览
- 提供专辑封面+CD机模拟
- 其他由你设计
