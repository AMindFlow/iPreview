# 规格目录规则

每个维度在各目录最多一个 Markdown 文件。同一维度沿用文件名和条目编号。

| 位置 | 记录内容 |
| --- | --- |
| `spike/<维度>.md` | 待讨论、实现或验证的改动。 |
| `official/<维度>.md` | 现行规格。 |
| `superseded/<维度>.md` | 曾正式提出、后来放弃或替换的条目。记录原条目、原因或触发撤销的 Issue。有后续条目时加链接。 |

每条规格写清要求、Issue 来源和验收条件。规格之间有共同约束时，链接到相关条目。设计决定与所属规格放在同一个文件里，可写明参考的其他条目。

使用[规格模板](../templates/spec.md)。批准、生效和验收见 [SDD 流程](../workflow/sdd.md)。
