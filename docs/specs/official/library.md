# 本地媒体库

## LIB-001 目录导入与扫描

- **要求** 通过系统目录选择器登记本地来源。自动识别单创作者和多创作者结构，双命中时提示选择。直属媒体可作为单个专辑。扫描与预览只读访问已登记来源，跳过隐藏文件、符号链接和重解析点。
- **来源** [需求 #1](https://github.com/AMindFlow/iPreview/issues/1)
- **验收** 两端导入共同样例的两种层级、混合结构和直属媒体；核对记录、计数和源文件清单。

## LIB-002 索引续用

- **要求** 本地 SQLite 保存来源与媒体身份。重启恢复索引。手动重扫刷新内容，保留已有媒体 ID；源盘离线和文件缺失的状态可见。合集成员在媒体离线期间可追溯。
- **来源** [需求 #1](https://github.com/AMindFlow/iPreview/issues/1)
- **验收** 重启、增减测试文件、模拟源盘离线然后恢复，检查记录可用性及专辑成员顺序。

## LIB-009 多创作者来源的浏览层级

- **要求** 打开多创作者来源时先选择创作者，进入后显示该创作者的专辑或作品。返回时回到创作者层。来源首页以创作者为浏览单位，同名专辑保留各自归属。单创作者来源的入口沿用 [LIB-001](#lib-001-目录导入与扫描)。
- **来源** [多创作者浏览 #6](https://github.com/AMindFlow/iPreview/issues/6)，旧版创作者列表进入创作者专辑的交互
- **验收** 导入包含至少两名创作者及同名专辑的样例。从来源首页依次进入两名创作者，核对各自专辑和媒体，返回创作者层。重启后复查路径，另验证单创作者来源。

## LIB-010 创作者和专辑层级键盘浏览

- **要求** 激活含下级文件夹的来源后，内容区支持方向键按可见排列选择创作者或专辑。首次进入文件夹页默认选中首项，Space 打开选中项。专辑或创作者内容区按 Esc 返回已有父层，并恢复刚离开的子项选择。到来源根层时保持当前层。独立预览与搜索输入处理各自的按键。
- **来源** [层级键盘浏览 #18](https://github.com/AMindFlow/iPreview/issues/18)、[快捷键调整 #21](https://github.com/AMindFlow/iPreview/issues/21)
- **验收** 在 Mac 的卡片网格和 Windows 的纵向列表分别用键盘选择第二位创作者，用 Space 进入创作者及其专辑，再逐级退出。检查返回后的高亮与焦点，以及在搜索框和预览中 Esc 的行为。

## LIB-011 重命名真实目录和媒体

- **要求** 在内容区选中创作者子目录、来源专辑或可用媒体后，Enter 打开重命名编辑。再次按 Enter 确认，Esc 取消。保留父目录。媒体编辑只接受主文件名，保留原扩展名。搜索和合集中的条目指向同一原文件。重命名完成后保留媒体身份、引用和合集成员顺序。
- **边界** 仅对已索引且可安全访问的本地条目执行。重命名支持 macOS 的 APFS，以及 Windows 的 NTFS 和 ReFS，以便中断后仍能核对文件身份。拒绝无效名称、同级冲突、符号链接或重解析点，以及会使另一已登记来源的路径或索引失效的重命名。已登记的来源根目录由侧栏管理。
- **恢复** 确认后先持久化更名记录，再更改磁盘名称并更新索引。无法提交索引更新时尝试恢复原名。中断后根据目录项名称和文件身份协调索引。磁盘操作拒绝覆盖。macOS 上外部程序同时替换所选路径时可能造成文件身份无法判定；此时保留恢复记录、暂停该来源重扫，并显示原路径和目标路径供手动核对。
- **来源** [快捷键与真实路径重命名 #21](https://github.com/AMindFlow/iPreview/issues/21)，旧版同目录重命名流程。
- **验收** 用合成来源验证文件、专辑和创作者改名、取消、同名冲突、仅大小写变化、重解析路径、旧索引升级及中断恢复。重扫、重启并核对路径、成员顺序、内容摘要和文件修改时间。使用另一份合成测试目录，避免操作现有媒体库。

数据约定见 [共享契约](../../../shared/README.md)。

## LIB-012 双击目录标题重命名

- **要求** 双击已打开的真实创作者或专辑标题进入行内编辑。Enter 或点击编辑框外提交并结束编辑，Esc 放弃更改。沿用 [LIB-011](#lib-011-重命名真实目录和媒体) 的路径校验和恢复流程。完成后更新当前导航路径。来源根目录遵从 LIB-011 的范围。
- **来源** [macOS 图库体验 #29](https://github.com/AMindFlow/iPreview/issues/29)，[Windows 图库体验 #31](https://github.com/AMindFlow/iPreview/issues/31)。
- **验收** 在合成库验证单击无编辑、双击进入行内编辑、点击空白区提交、点击子目录同时提交并导航，以及 Esc 取消。核对标题、磁盘路径、文件内容和虚拟引用。
