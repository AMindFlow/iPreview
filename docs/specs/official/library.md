# 本地媒体库

## LIB-001 目录导入与扫描

- **要求** 通过系统目录选择器登记本地来源。自动识别单创作者和多创作者结构，双命中时提示选择。直属媒体可作为单个专辑。扫描与预览只读访问已登记来源，跳过隐藏文件、符号链接和重解析点。
- **来源** [需求 #1](https://github.com/AMindFlow/iPreview/issues/1)
- **验收** 两端导入共同样例的两种层级、混合结构和直属媒体；核对记录、计数和源文件清单。

## LIB-002 索引续用

- **要求** 本地 SQLite 保存来源与媒体身份。重启恢复索引。手动重扫刷新内容，保留已有媒体 ID；源盘离线和文件缺失的状态可见。合集成员在媒体离线期间可追溯。
- **来源** [需求 #1](https://github.com/AMindFlow/iPreview/issues/1)
- **验收** 重启、增减测试文件、模拟源盘离线然后恢复，检查记录可用性及合集成员顺序。

## LIB-006 两种视频作品结构

- **要求** 从来源根目录或专辑层识别两种作品。主视频和图片分组由目录层级与受支持的媒体类型确定。示例中的文件名和目录名可替换。
- **简化结构** 作品根目录有一个视频和一个存放图片的直属目录。直属图片目录形成一册并沿用目录名。根目录仅有一张图片时用作可选样张。已有的「官方样张」同名主干图片优先作为样张，其余根目录图片保留为普通媒体。
- **完整结构** 主视频在一个直属子目录内。与视频目录并列的图册容器下有一册或多册，每册直接存放图片，容器本身无直属媒体。可另有一个并列的纯图片目录作为样张。各册可用旧式主干名「封面」标识一张封面，缺省时用首张照片作为分组缩略图。样张和专用封面均可省略，外部样张来源单独确认。
- **结构冲突** 多个可能的主视频、简化结构有多个直属图片册或多个旧式样张提示、完整结构有多个样张目录、同册多个旧式封面提示或图册只含专用封面时，按普通来源扫描。普通图片相册、仅有直属媒体的相册及缺少二级图册的视频专辑与图片专辑并列结构沿用原布局。
- **索引** 导入与重扫在同一事务更新媒体及作品归组。重扫保留已有来源布局和已有媒体身份。离线保留归组，恢复后重扫更新。原始媒体只读，见 [LIB-001](#lib-001-目录导入与扫描)。作品交互见 [PRE-004](preview.md#pre-004-视频作品的影碟与图册预览)。
- **来源** [作品目录 #62](https://github.com/AMindFlow/iPreview/issues/62)，承接[首版 #1](https://github.com/AMindFlow/iPreview/issues/1)。
- **验收** 分别导入以下两种作品及其父目录，复验旧版完整及简化结构与普通图片相册。核对影片、样张和真实图册归属，两端均能打开无样张作品。重启、离线、恢复重扫后核对作品、成员及媒体身份，比较源文件快照。

```text
work/
├── movie/
│   └── main.mp4
├── stills/                 可选
│   └── frame.jpg
└── books/
    ├── Set 2/
    │   └── 1.png
    └── Set 10/
        ├── 封面.png        可选
        └── 1.png

album/
├── video.mp4
├── frame.jpg               可选
└── pictures/
    ├── 1.png
    └── 2.png
```

## LIB-009 多创作者来源的浏览层级

- **要求** 打开多创作者来源时先选择创作者，进入后显示该创作者的专辑或作品。返回时回到创作者层。来源首页以创作者为浏览单位，同名专辑保留各自归属。单创作者来源的入口沿用 [LIB-001](#lib-001-目录导入与扫描)。
- **来源** [多创作者浏览 #6](https://github.com/AMindFlow/iPreview/issues/6)，旧版创作者列表进入创作者专辑的交互
- **验收** 导入包含至少两名创作者及同名专辑的样例。从来源首页依次进入两名创作者，核对各自专辑和媒体，返回创作者层。重启后复查路径，另验证单创作者来源。

## LIB-010 创作者和专辑层级键盘浏览

- **要求** 激活含下级文件夹的来源后，内容区支持方向键按可见排列选择创作者或专辑。首次进入文件夹页默认选中首项，Space 打开选中项。选中视频作品目录时，Space 打开 [PRE-004](preview.md#pre-004-视频作品的影碟与图册预览) 中的作品预览。专辑或创作者内容区按 Esc 返回已有父层，并恢复刚离开的子项选择。到来源根层时保持当前层。独立预览与搜索输入处理各自的按键。
- **要求** 旧多创作者来源重扫后，识别到的直属视频作品可在来源首页打开。Space 进入作品预览，作品文件列表的父级为来源首页，返回时恢复选中的作品。
- **来源** [层级键盘浏览 #18](https://github.com/AMindFlow/iPreview/issues/18)、[快捷键调整 #21](https://github.com/AMindFlow/iPreview/issues/21)
- **验收** 在两端的可见卡片网格分别用键盘选择第二位创作者，用 Space 进入创作者及其专辑，再逐级退出。检查返回后的高亮与焦点，以及在搜索框和预览中 Esc 的行为。用保留旧多创作者布局的合成来源复验直属作品和创作者内作品的入口、父级及返回时的选中恢复。

## LIB-011 重命名真实目录和媒体

- **要求** 在内容区选中创作者子目录、来源专辑或可用媒体后，Enter 打开重命名编辑。再次按 Enter 确认，Esc 取消。保留父目录。媒体编辑只接受主文件名，保留原扩展名。搜索和合集中的条目指向同一原文件。重命名完成后保留媒体身份、引用和合集成员顺序。
- **边界** 仅对已索引且可安全访问的本地条目执行。重命名支持 macOS 的 APFS，以及 Windows 的 NTFS 和 ReFS，以便中断后仍能核对文件身份。拒绝无效名称、同级冲突、符号链接或重解析点，以及会使另一已登记来源的路径或索引失效的重命名。已登记的来源根目录由侧栏管理。
- **恢复** 确认后先持久化更名记录，再更改磁盘名称并更新索引。无法提交索引更新时尝试恢复原名。中断后根据目录项名称和文件身份协调索引。磁盘操作拒绝覆盖。macOS 上外部程序同时替换所选路径时可能造成文件身份无法判定；此时保留恢复记录、暂停该来源重扫，并显示原路径和目标路径供手动核对。
- **来源** [快捷键与真实路径重命名 #21](https://github.com/AMindFlow/iPreview/issues/21)，旧版同目录重命名流程。
- **验收** 用合成来源验证文件、专辑和创作者改名、取消、同名冲突、仅大小写变化、重解析路径、旧索引升级及中断恢复。重扫、重启并核对路径、成员顺序、内容摘要和文件修改时间。使用另一份合成测试目录，避免操作现有媒体库。

数据约定见 [共享契约](../../../shared/README.md)。

## LIB-012 双击目录标题重命名

- **要求** 双击已打开的真实创作者或专辑标题进入行内编辑。Enter 或点击编辑框外提交并结束编辑，Esc 放弃更改。沿用 [LIB-011](#lib-011-重命名真实目录和媒体) 的路径校验和恢复流程。完成后更新当前导航路径。来源根目录遵从 LIB-011 的范围。
- **来源** [macOS 图库体验 #29](https://github.com/AMindFlow/iPreview/issues/29)，[Windows 图库体验 #31](https://github.com/AMindFlow/iPreview/issues/31)。
- **验收** 在合成库验证单击无编辑、双击进入行内编辑、点击空白区提交、点击子目录同时提交并导航，以及 Esc 取消。核对标题、磁盘路径、文件内容和虚拟引用。

## LIB-013 添加、重扫和删除媒体源

- **要求** 侧栏「源」右侧的加号打开现有导入流程。来源行支持右键菜单和光标悬停时用触摸板向左滑动，显示圆底重新扫描和删除按钮。向右滑动或点击操作区外时收起，外部点击照常生效。
- **要求** 删除前显示来源名称和影响。取消保留原状。确认后在同一事务移除该来源的索引、专辑组织和合集中的相关引用，保留原文件、其他来源及合集剩余引用的顺序。当前正浏览该来源时回到媒体库。其他窗口写入后先刷新再提示重新核对。待恢复重命名的来源须先处理原恢复状态。
- **来源** [功能细节优化 #75](https://github.com/AMindFlow/iPreview/issues/75)。
- **验收** 双端用加号添加两个媒体源。分别从右键和实物触摸板重扫独立来源、取消删除和确认删除其中一个来源。验证索引、跨来源合集、重启、离线来源删除和源文件快照。重启后导回同一目录，新来源和媒体应获得新身份，旧合集引用保持已移除。
