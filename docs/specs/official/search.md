# 搜索

## SRCH-001 目录名与文件名

- **要求** 搜索可独立选择目录名、文件名。精确匹配使用规范化后的完整名称。模糊匹配按原文完全命中、前缀、子串、拼音全拼、首字母、拼写容错排序。
- **来源** [需求 #1](https://github.com/AMindFlow/iPreview/issues/1)
- **验收** 在两端运行相同查询，覆盖各级路径、范围开关、规范化、排序、拼音和拼写容错。结果显示文件及对应路径。

匹配归一化与排序见 [共享契约](../../../shared/README.md)。

## SRCH-002 macOS 当前页搜索和全局搜索

- **要求** 当前页搜索范围随所在层级变化。来源和创作者页可查找其子树，真实专辑仅查找当前专辑，虚拟专辑仅查找本专辑的成员。进入其他层级时清除当前页查询。
- **要求** 点击侧栏「媒体库」右侧放大镜打开居中的全局搜索。结果显示目录或文件及路径，方向键选中结果。Enter 进入目录，或进入文件所在目录并定位文件。选择文件后 Space 切换预览，Esc 可返回搜索或关闭搜索面板。查询和媒体索引保存在本地。
- **来源** [macOS 图库体验 #29](https://github.com/AMindFlow/iPreview/issues/29)，用户提供的 Spotlight 参考。
- **验收** 在两个来源中放入同名文件和同名专辑。分别从来源、创作者、真实专辑和虚拟专辑搜索，核对范围边界。全局分别打开目录、定位文件、预览和回到结果。覆盖拼音、空格和 Escape。
