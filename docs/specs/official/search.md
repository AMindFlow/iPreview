# 搜索

## SRCH-001 目录名与文件名

- **要求** 搜索可独立选择目录名、文件名。精确匹配使用规范化后的完整目录名或文件名。文件可省略最后一个后缀。查询以支持的媒体后缀结尾时匹配完整文件名，其余查询保留名称中的点号。模糊匹配按原文完全命中、前缀、子串、拼音全拼、首字母、拼写容错排序。
- **来源** [需求 #1](https://github.com/AMindFlow/iPreview/issues/1)
- **验收** 在两端运行相同查询，覆盖各级路径、范围开关、规范化、排序、拼音和拼写容错。验证同名图片的不同后缀、指定后缀和目录完整名称。结果显示文件及对应路径。

匹配归一化与排序见 [共享契约](../../../shared/README.md)。

## SRCH-002 当前范围和全局搜索

- **要求** ⌘F／Ctrl+F 打开当前范围搜索，⇧⌘F／Ctrl+Shift+F 或侧栏「媒体库」右侧的放大镜打开全局搜索。两者使用同一个居中面板，打开即聚焦输入框。页内右上角不再放置搜索框。预览或名称编辑期间保留当前操作焦点。
- **要求** 当前范围搜索随页面变化。媒体库总览涵盖所有来源，来源和创作者页搜索各自子树，真实专辑搜索当前专辑，合集仅搜索成员文件。全局搜索涵盖所有来源。按 ⌘0／Ctrl+0 在两个搜索域之间切换，面板显示当前搜索域及快捷键。切换时保留搜索文字、精确状态和文件／目录筛选。
- **要求** 默认同时搜索文件和目录。⌘1／Ctrl+1 只搜文件，⌘2／Ctrl+2 只搜目录，重复按当前筛选恢复搜索两者。输入 @ 后按空格启用精确匹配，移除输入框中的触发字符并显示「精确匹配」标签，接受全角字符。精确模式下 Esc 先回到模糊搜索，保留关键词与面板；再次按 Esc 关闭面板。匹配规则沿用 [SRCH-001](#srch-001-目录名与文件名)。
- **要求** 显示结果及路径，方向键选中结果。Enter 进入目录，或进入文件所在目录并定位文件。范围搜索中的合集成员在当前合集定位。选择文件后 Space 切换预览，预览关闭后回到搜索。查询和媒体索引保存在本地。
- **来源** [图库体验 #29](https://github.com/AMindFlow/iPreview/issues/29)、[图库交互复验 #32](https://github.com/AMindFlow/iPreview/issues/32)、[Windows 图库体验 #31](https://github.com/AMindFlow/iPreview/issues/31)、[搜索快捷键 #35](https://github.com/AMindFlow/iPreview/issues/35)和[统一搜索面板 #37](https://github.com/AMindFlow/iPreview/issues/37)。
- **验收** 分别从来源、创作者、真实专辑和合集搜索，核对范围和结果定位。验证两个入口的光标、在两域间往返切换及筛选保留。核对 @ 单独输入、空格激活和移除触发字符、同名不同后缀、Esc 退出精确模式和关闭面板。回归全角字符、输入法、文件预览和返回结果。

## SRCH-003 创作者与专辑分类标记

同一编号的后续交付见[分类结果与标签搜索](#分类结果与标签搜索)。

- **要求** 根据已索引的来源布局标记匹配的创作者和专辑，显示类别图标、名称及父路径。单创作者来源根和多创作者来源中的创作者层标记为创作者。两种创作者布局中的专辑层及直属媒体来源根标记为专辑。同名结果按完整来源路径区分。
- **边界** 创作者和专辑属于目录筛选。匹配、作用域和键盘行为沿用 SRCH-001、002。
- **来源** [分类与标签搜索 #60](https://github.com/AMindFlow/iPreview/issues/60)，旧版图片库组织管理 R-004 与 AC-005。
- **验收** 从单创作者、多创作者来源和直属媒体来源搜索，核对类别与父路径。验证两个创作者的同名专辑及同名文件，切换到仅目录／仅文件，并用方向键和 Enter 前往正确位置。

### 分类结果与标签搜索

- **要求** 匹配结果按创作者、专辑、目录和文件分组，组内沿用原匹配排序。方向键跨组选择，分组标题不参与结果选择。
- **要求** 标签筛选可从菜单选择，也可在输入开头输入 `#` 或 `＃` 调出联想。标签联想按完整名称、前缀、子串排序，允许上下键选择、回车应用。应用后可继续输入文件或目录名，也可清除标签筛选。当前范围、全局范围、精确匹配和文件／目录开关保持生效。
- **要求** 选中标签后仅匹配关联的来源专辑及其成员文件。合集内的当前范围仅匹配属于该合集且位于所选标签专辑的成员文件。普通查询仍按 SRCH-001 匹配，入册及全库维护见 [ALB-002](virtual-albums.md#alb-002-旧版标签收藏评分与封面)。
- **来源** [#60](https://github.com/AMindFlow/iPreview/issues/60)，承接首版 [#1](https://github.com/AMindFlow/iPreview/issues/1) 的旧版结果分组与标签搜索。
- **验收** 用同名创作者、目录、专辑、文件与标签验证分类和父路径。输入标签名称的一部分，用上下键切换联想并回车应用。检查范围切换、仅查目录、仅查文件、追加精确文件名、清除标签、结果定位与文件预览。标签全库重命名及删除后复查联想和过滤结果。
