# 合集

## ALB-001 跨来源媒体组织

- **要求** 创建和重命名合集、跨来源引用图片和视频、调整顺序及移除引用。成员顺序持久化。源文件离线时保留引用。
- **来源** [需求 #1](https://github.com/AMindFlow/iPreview/issues/1)
- **验收** 选取两个不同来源的媒体加入同一合集，重排和重启后保持次序。移除引用后原文件仍可从来源浏览。

## ALB-002 旧版标签、收藏、评分与封面

- **要求** 实体来源专辑的详情在标题下显示评分及标签。标签右上角在悬停时显示红色移除按钮，标签区右侧悬停显示玻璃加号，沿用新增与复用标签流程。移除只解除当前专辑的关联。媒体库的「管理标签」可在全库重命名、删除标签及其关联。按标签筛选见 [SRCH-003](search.md#分类结果与标签搜索)。
- **要求** [已识别的视频作品](library.md#lib-006-两种视频作品结构)以作品根目录作为来源专辑。主视频、样张及写真图片共用标签和封面设置，组内目录可供搜索定位。
- **要求** 收藏与评分独立。详情与对应侧栏条目右侧提供同一个收藏状态的五角星按钮，点击侧栏收藏按钮时保留当前位置。直属媒体源本身是专辑，嵌套专辑或作品进入后在所属来源下显示对应条目。标题下的五颗星可交互设置 0 至 5 分，每半星一档，可清为未评分。
- **要求** 专辑标题左侧的封面可点击打开模态封面设置，专辑卡片和标题使用同一封面。自动选自然排序的首张可用图片。手选一张，或按选择次序拼合 2–4 张。选片排序遵循[媒体排序](browsing.md#brw-004-媒体排序)，保留已选图片及拼图次序。任一配置图片暂不可用时退回自动封面，自动候选为空时显示占位。媒体恢复后恢复配置封面。所有操作只写入 iPreview 资料库。
- **来源** [#59](https://github.com/AMindFlow/iPreview/issues/59)，承接首版 [#1](https://github.com/AMindFlow/iPreview/issues/1) 的旧版图库组织需求。
- **验收** 升级非空旧库后核对已有合集及其顺序。用直属来源、嵌套专辑和作品核对双入口收藏与原位置，悬停移除标签、点加号附加或复用标签，再从全库重命名和删除。收藏一张专辑并设为零分，给另一张设半星，重启后核对状态，清空其中一个评分再核对收藏。从标题左侧打开封面设置，依次选择自动、手选和拼图。移走一张配置图片重新扫描检查回退，归还后再扫描核对恢复。

## ALB-003 合集删除

- **要求** 从合集工具栏选择「删除合集」后，应用内确认界面显示合集名称，提供删除和取消。取消不写入。确认删除后只移除当前合集及其媒体引用，原始媒体及其他合集保留。成功后显示媒体库并更新侧栏合集列表。写入失败时保留当前合集及选中项，可重试。其他窗口修改资料库后，先刷新并提示重新核对。
- **来源** [合集删除 #61](https://github.com/AMindFlow/iPreview/issues/61)，[总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)。
- **验收** 用跨来源合集验证取消、确认、删除后返回列表、连续删除／创建及失败恢复。核对失联引用随合集删除、其他合集成员及顺序保留，并对照源文件快照。

## ALB-004 从来源专辑批量添加媒体

- **要求** 空合集的中央图标以同色线条在图标内居中显示「添加媒体」加号。指针悬停时高亮按钮边框，按住时还显示底色变化。边框和按下反馈遵循系统的对比度及动画设置。有成员时可从工具栏打开同一选片器。从来源／创作者和专辑筛选已有索引，查看缩略图，勾选图片和视频或全选当前专辑的可用项。切换专辑保留待添加项，提交前可以逐项取消选择。界面见 [UI-002](appearance.md#ui-002-合集选片器)。
- **要求** 确认后按选中顺序一次追加引用。保留已有成员次序并按媒体身份去重，已经加入或离线失联的条目不供选择。取消保留合集原状。整个过程只读访问源文件。
- **来源** [跨专辑选片 #22](https://github.com/AMindFlow/iPreview/issues/22)，旧版合集的跨创作者选片流程。
- **验收** 两端核对空合集图标内的加号居中且与图标线条同色。悬停核对高亮边框，按住核对底色变化，用点击及键盘激活打开选片器。跨两个来源选图片和视频，全选一个专辑并撤回一项，确认后检查顺序。重复打开检查去重、取消与离线过滤。重启后核对引用顺序和源文件快照。

## ALB-005 批量移除引用

- **要求** 有成员的合集提供「调整」。在图标、列表和画廊中逐项勾选或撤回，切换布局保留勾选和数量。「取消」、Esc 或离开当前合集退出当前模式。
- **要求** 点「移除引用」时一次移除所选项，包括失联的媒体引用。保留剩余成员的相对顺序、其他合集中的引用和源文件。
- **设计决定** 沿用各平台已有的合集工具栏，将其操作区切换为已选数量、取消和移除。两端以蓝色勾选表示选中项。仅在已勾选项右下显示标记。
- **来源** [批量移除 #25](https://github.com/AMindFlow/iPreview/issues/25)
- **验收** 对跨来源的图片与视频勾选、撤回、切换布局及取消。批量移除后重启检查成员次序、其他合集的引用及源文件快照。

## ALB-006 合集标题与拖动排序

- **要求** 双击合集标题就地改名。点击编辑框外或 Enter 提交，Esc 取消。「调整」有清晰框体。「添加媒体」加号仍打开跨专辑选片器。
- **要求** 只在「调整」中按住图标、列表项或画廊缩略图再拖动进行排序。条目无需常驻手柄。短按勾选或取消勾选，拖动保持勾选状态。拖动时指示插入点，成功投放后保存当前合集的引用顺序，取消保留原次序。真实目录浏览移除单文件加入合集入口，两类页面均移除布局控件右侧的省略号。Windows 中拖到可滚动列表的边缘时继续滚动，松手时按当前位置的条目落位。
- **来源** [macOS 图库体验 #29](https://github.com/AMindFlow/iPreview/issues/29)，旧版合集插入提示，以及[图库交互复验 #32](https://github.com/AMindFlow/iPreview/issues/32)及 [Windows 图库体验 #31](https://github.com/AMindFlow/iPreview/issues/31)。
- **验收** 验证双击编辑、点击框外提交和取消。分别在三种布局进入调整、勾选、拖动和取消，检查普通浏览拖动保持原顺序。在 Windows 的长合集中拖到边缘滚动后投放，核对新位置。退出重开核对次序，核对其他合集和源文件快照。
