# 虚拟专辑

## ALB-001 跨来源媒体组织

- **要求** 创建和重命名虚拟专辑、跨来源引用图片和视频、调整顺序及移除引用。成员顺序持久化。源文件离线时保留引用。
- **来源** [需求 #1](https://github.com/AMindFlow/iPreview/issues/1)
- **验收** 选取两个不同来源的媒体加入同一专辑，重排和重启后保持次序。移除引用后原文件仍可从来源浏览。

## ALB-004 从来源专辑批量添加媒体

- **要求** 空虚拟专辑的中央图标提供「添加媒体」加号，有成员时可从工具栏打开同一选片器。从来源／创作者和专辑筛选已有索引，查看缩略图，勾选图片和视频或全选当前专辑的可用项。切换专辑保留待添加项，提交前可以逐项取消选择。界面见 [UI-002](appearance.md#ui-002-虚拟专辑选片器)。
- **要求** 确认后按选中顺序一次追加引用。保留已有成员次序并按媒体身份去重，已经加入或离线失联的条目不供选择。取消保留专辑原状。整个过程只读访问源文件。
- **来源** [跨专辑选片 #22](https://github.com/AMindFlow/iPreview/issues/22)，旧版虚拟合集的跨创作者选片流程。
- **验收** 从空专辑中的加号打开选片器，跨两个来源选图片和视频，全选一个专辑并撤回一项，确认后检查顺序。重复打开检查去重、取消与离线过滤。重启后核对引用顺序和源文件快照。

## ALB-005 批量移除引用

- **要求** 有成员的虚拟专辑提供「调整」。在图标、列表和画廊中逐项勾选或撤回，切换布局保留勾选和数量。「取消」、Esc 或离开当前专辑退出当前模式。
- **要求** 点「移除引用」时一次移除所选项，包括失联的媒体引用。保留剩余成员的相对顺序、其他专辑中的引用和源文件。
- **设计决定** 沿用各平台已有的专辑工具栏，将其操作区切换为已选数量、取消和移除。两端以蓝色勾选表示选中项。仅在已勾选项右下显示标记。
- **来源** [批量移除 #25](https://github.com/AMindFlow/iPreview/issues/25)
- **验收** 对跨来源的图片与视频勾选、撤回、切换布局及取消。批量移除后重启检查成员次序、其他专辑的引用及源文件快照。

## ALB-006 专辑标题与拖动排序

- **要求** 双击虚拟专辑标题就地改名。点击编辑框外或 Enter 提交，Esc 取消。「调整」有清晰框体。「添加媒体」加号仍打开跨专辑选片器。
- **要求** 只在「调整」中按住图标、列表项或画廊缩略图再拖动进行排序。条目无需常驻手柄。短按勾选或取消勾选，拖动保持勾选状态。拖动时指示插入点，成功投放后保存当前专辑的引用顺序，取消保留原次序。真实目录浏览移除单文件加入虚拟专辑入口，两类页面均移除布局控件右侧的省略号。
- **来源** [macOS 图库体验 #29](https://github.com/AMindFlow/iPreview/issues/29)，旧版合集插入提示，以及[图库交互复验 #32](https://github.com/AMindFlow/iPreview/issues/32)及 [Windows 图库体验 #31](https://github.com/AMindFlow/iPreview/issues/31)。
- **验收** 验证双击编辑、点击框外提交和取消。分别在三种布局进入调整、勾选、拖动和取消，检查普通浏览拖动保持原顺序。退出重开核对次序，核对其他专辑和源文件快照。
