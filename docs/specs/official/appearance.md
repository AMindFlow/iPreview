# 应用视觉

## UI-001 应用图标

- **要求** 白色圆角方形底承载蓝紫星云球与星芒。两条独立的闭合轨道各自绕过主星球，使用不同的倾角和扁率。靠后的环段与球体相交时被遮挡，靠前的环段盖在球体前方，轨道交会处保持各自走向。外围行星与媒体符号沿轨道布置，使用蓝青渐变。小尺寸保留星球及双环轮廓。macOS 和 Windows 使用由同一可编辑 SVG 主稿导出的平台图标。
- **来源** [星云轨道图标 #16](https://github.com/AMindFlow/iPreview/issues/16)，用户提供的轨道构图及蓝青配色参考
- **验收** 在矢量主稿中检查两条完整的环。对照渲染核对各环前后段的连续性、遮挡与外围元素的位置。检查常用尺寸在浅、深背景上的呈现以及 Finder、Dock、Windows 资源管理器和任务栏的应用图标。


## 设计决定

- [SVG 主稿](../../../shared/assets/AppIcon.svg)是两端共同来源。macOS 将多尺寸 ICNS 放入应用包。Windows 将多尺寸 ICO 嵌入可执行文件，同一个 ICO 随包提供给窗口和任务栏。

## UI-002 虚拟专辑选片器

- **要求** 在原生浅色面板顶部选择来源／创作者与专辑，中央使用全宽媒体缩略图。选中项使用与媒体库一致的蓝色和可辨识的勾选。底部胶片条按添加顺序横向排列待添加缩略图，可滚动并逐项撤回。确认和取消固定在底部。
- **设计决定** 按用户选择采用底部胶片条，参考旧版跨来源待添加流程和首版浅色图库。确认时发现文件不可用，提示后仍可操作胶片条和页脚。并排分栏方案随交付材料保留。
- **来源** [跨专辑选片 #22](https://github.com/AMindFlow/iPreview/issues/22)，用户指定的美术流程。
- **验收** 在两端从空专辑加号进入选片器。用有多条暂存媒体的同一状态对照采用方案，核对顶部选择、中央缩略图和底部胶片条。对待添加项做横向滚动和撤回测试。调整 Windows 窗口宽度并复测错误状态，确认主要操作仍可见。

## UI-003 macOS 原生液态玻璃

- **要求** macOS 26 及以上使用原生窗口工具栏、分栏侧边栏和系统绘制的红黄绿窗口按钮。侧边栏延续到窗口控制区域，采用系统外观随浅色、深色和辅助功能变化。主要交互控件和全局搜索使用系统液态玻璃，媒体内容保持清晰。macOS 15 使用系统材质。
- **要求** 直属媒体目录用文件夹，单创作者来源用个人，多创作者来源用多人。离线来源保留结构图标并附可见状态。
- **设计决定** 采用 Safari 参考中的连续侧栏和浅层微透明。按苹果规范将玻璃用于导航与控件，保持内容层和控制层清楚分离。[Apple 迁移指南](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass) · [Apple 材质规范](https://developer.apple.com/design/human-interface-guidelines/materials)
- **来源** [macOS 图库体验 #29](https://github.com/AMindFlow/iPreview/issues/29)，用户提供的 Safari 与 iPreview 窗口对照。
- **验收** 在同一 macOS 版本对照 Safari，检查红绿灯、侧栏及其上方区域是否连续，核对三种来源图标和离线提示。打开搜索、预览和选片器，核对文字、媒体及交互状态在不同系统外观下可辨识。

## UI-004 Windows 图库材质与来源图标

- **要求** 保留 Windows 原生窗框。图库侧栏、全局搜索和媒体预览使用 WinUI 系统材质，支持系统关闭透明效果时的回退。直属媒体目录用文件夹，单创作者来源用个人，多创作者来源用多人，离线状态保持可见。
- **来源** [Windows 图库体验 #31](https://github.com/AMindFlow/iPreview/issues/31)，[WinUI 应用内 Acrylic](https://learn.microsoft.com/en-us/windows/apps/develop/ui/in-app-acrylic)。
- **验收** 在 Windows 11 检查来源图标、离线标识、全局搜索与预览的材质，核对系统降低视觉效果时主要控件及媒体仍可辨识。
