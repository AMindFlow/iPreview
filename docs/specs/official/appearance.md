# 应用视觉

## UI-001 应用图标

- **要求** 白色圆角方形底承载蓝紫星云球与星芒。两条独立的闭合轨道各自绕过主星球，使用不同的倾角和扁率。靠后的环段与球体相交时被遮挡，靠前的环段盖在球体前方，轨道交会处保持各自走向。外围行星与媒体符号沿轨道布置，使用蓝青渐变。小尺寸保留星球及双环轮廓。macOS 和 Windows 使用由同一可编辑 SVG 主稿导出的平台图标。
- **来源** [星云轨道图标 #16](https://github.com/AMindFlow/iPreview/issues/16)，用户提供的轨道构图及蓝青配色参考
- **验收** 在矢量主稿中检查两条完整的环。对照渲染核对各环前后段的连续性、遮挡与外围元素的位置。检查常用尺寸在浅、深背景上的呈现以及 Finder、Dock、Windows 资源管理器和任务栏的应用图标。


## 设计决定

- [SVG 主稿](../../../shared/assets/AppIcon.svg)是两端共同来源。macOS 将多尺寸 ICNS 放入应用包。Windows 将多尺寸 ICO 嵌入可执行文件，同一个 ICO 随包提供给窗口和任务栏。

## UI-002 合集选片器

- **要求** 在适应系统外观的原生面板顶部选择来源／创作者与专辑，中央使用全宽媒体缩略图。选中项使用与媒体库一致的蓝色和可辨识的勾选。底部胶片条按添加顺序横向排列待添加缩略图，可滚动并逐项撤回。确认和取消固定在底部。
- **设计决定** 按用户选择采用底部胶片条，参考旧版跨来源待添加流程和首版浅色图库。确认时发现文件不可用，提示后仍可操作胶片条和页脚。并排分栏方案随交付材料保留。
- **来源** [跨专辑选片 #22](https://github.com/AMindFlow/iPreview/issues/22)，用户指定的美术流程。
- **验收** 在两端从空合集加号进入选片器。用有多条暂存媒体的同一状态对照采用方案，核对顶部选择、中央缩略图和底部胶片条。对待添加项做横向滚动和撤回测试。调整 Windows 窗口宽度并复测错误状态，确认主要操作仍可见。

## UI-003 macOS 原生液态玻璃

- **要求** macOS 26 及以上使用原生窗口工具栏、分栏侧边栏和系统绘制的红黄绿窗口按钮。侧边栏延续到窗口控制区域，采用系统外观随浅色、深色和辅助功能变化。主要交互控件和全局搜索使用系统液态玻璃，媒体内容保持清晰。macOS 15 使用系统材质。
- **要求** 直属媒体目录用文件夹，单创作者来源用个人，多创作者来源用多人。离线来源保留结构图标并附可见状态。
- **设计决定** 采用 Safari 参考中的连续侧栏和浅层微透明。按苹果规范将玻璃用于导航与控件，保持内容层和控制层清楚分离。[Apple 迁移指南](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass) · [Apple 材质规范](https://developer.apple.com/design/human-interface-guidelines/materials)
- **来源** [macOS 图库体验 #29](https://github.com/AMindFlow/iPreview/issues/29)，用户提供的 Safari 与 iPreview 窗口对照。
- **验收** 在同一 macOS 版本对照 Safari，检查红绿灯、侧栏及其上方区域是否连续，核对三种来源图标和离线提示。打开搜索、预览和选片器，核对文字、媒体及交互状态在不同系统外观下可辨识。

## UI-004 Windows 图库材质与来源图标

- **要求** 保留 Windows 原生窗框。图库侧栏、全局搜索和媒体预览使用 WinUI 系统材质，支持系统关闭透明效果时的回退。直属媒体目录用文件夹，单创作者来源用个人，多创作者来源用多人，离线状态保持可见。
- **要求** Windows 图库沿用 Mac 版的标题、侧栏与工具布局，浏览方式使用紧凑的原生控件。列表列头与项目列对齐，搜索结果内容、状态与底部操作保持一致间距。图库、全局搜索和选片器使用 [UI-007](#ui-007-主题选择与恢复) 的主题，并支持系统对比度主题。
- **设计决定** Windows 采用与 Mac 对应的扁平「源」「合集」侧栏，创作者与专辑在内容区逐级进入。导入与侧栏切换使用紧凑顶部操作，标题、层级摘要、重新扫描、展示切换和合集操作按 Mac 的区域位置排列，移除固定底部工具条。通过统一内容边缘、网格比例、列表列及画廊浏览条对齐现有流程。Windows 保留原生窗框。
- **来源** [双端布局对齐 #47](https://github.com/AMindFlow/iPreview/issues/47)、[Windows 图库体验 #31](https://github.com/AMindFlow/iPreview/issues/31)、[预览控制与 Windows 界面对齐 #35](https://github.com/AMindFlow/iPreview/issues/35)及[WinUI 应用内 Acrylic](https://learn.microsoft.com/en-us/windows/apps/develop/ui/in-app-acrylic)。
- **验收** 在 Windows 11 检查来源图标、离线标识、全局搜索与预览的材质。调整窗口宽度，比较标题、搜索、操作组及列表列头和内容的边缘。核对浅色、深色及回退材质中的可读性和焦点。在相近窗口尺寸、同一源和合集中并排对比两端，检查层级方向键、Space 进入、Esc 返回和标题重命名。

## UI-005 侧栏操作与媒体库用语

- **要求** macOS 侧栏展开／收起按钮紧邻原生红绿灯，与窗口控件成组。导入文件夹与主题按钮组成右侧一组，随展开后的侧栏右边缘对齐。收起时两组仍保持可辨识间隔。各按钮与红绿灯同高，使用小图标。保持原有窗口控件与导入快捷键。Windows 的导入按钮显示于侧栏。
- **要求** 侧栏展开／收起、导入、全局搜索与新建合集图标悬停时显示温和且可辨识的反馈，按下和禁用状态保持一致。收起侧栏后显示展开图标，展开时显示收起图标。侧栏展开、收起和状态图标变化使用连续过渡，并尊重系统减少动态效果。
- **要求** 两端媒体库分组使用「源」与「合集」。新建、详情、选片、调整和提示使用「合集」，真实媒体目录仍称「专辑」。已有合集及其成员持续可读。
- **来源** [侧栏按钮与用语 #41](https://github.com/AMindFlow/iPreview/issues/41)、[Mac 标题栏对齐 #43](https://github.com/AMindFlow/iPreview/issues/43)、[侧栏交互反馈 #45](https://github.com/AMindFlow/iPreview/issues/45)
- **验收** 在 macOS 展开、收起及拖动侧栏宽度，核对侧栏按钮始终紧邻红绿灯，导入与主题成组并保持间隔。检查悬停、侧栏图标与过渡，再开启减少动态效果复查。验证原生窗口控件、导入快捷键和预览退出后的恢复。两端检查导入入口的位置及唯一性，打开原有文件夹选择器，再核对「源」、新建合集、空合集及选片文案。打开已有合集，检查名称和成员。

## UI-006 媒体展示切换器

- **要求** 图标、列表、画廊三种展示使用紧凑玻璃胶囊切换器。选中项有独立的圆形高亮，未选中项悬停时显示柔和反馈。macOS 26 及以上使用原生液态玻璃，macOS 15 使用系统材质。Windows 对齐轮廓、位置和状态反馈，采用系统材质及透明效果回退。
- **来源** [侧栏与控件交互反馈 #45](https://github.com/AMindFlow/iPreview/issues/45)、[双端布局对齐 #47](https://github.com/AMindFlow/iPreview/issues/47)及用户提供的 Finder 玻璃胶囊参考图。
- **验收** 两端在相同专辑依次点击三种展示，核对图标、选中项、悬停反馈和选中媒体保留。复验展示快捷键，检查浅深外观、macOS 15 和 Windows 关闭透明效果时的可读性。

## UI-007 主题选择与恢复

- **要求** macOS 主题按钮位于标题栏的导入按钮旁，以太阳或月亮显示实际外观。悬停时显示太阳、斜线和月亮。普通点击切换到相反的显式外观。在按钮上悬停并按住 Option 打开菜单，可选「自动」「明亮」「黑暗」。辅助功能「选择主题」操作也可打开菜单。Windows 主题菜单位于侧栏「媒体库」行。
- **要求** 首次启动跟随系统。选择立即生效并按当前用户保存，重启后恢复。显式主题覆盖系统的深浅偏好。
- **要求** 标题栏、侧栏、媒体库、搜索、预览和选片器使用同一主题，按平台支持继续响应系统对比度、透明和动态效果设置。玻璃和系统材质回退沿用 [UI-003–006](#ui-003-macos-原生液态玻璃)。
- **来源** [主题选择 #64](https://github.com/AMindFlow/iPreview/issues/64)，承接[首版 #1](https://github.com/AMindFlow/iPreview/issues/1)的旧版功能。
- **验收** 按[主题验收步骤](../../project/acceptance.md#主题选择与恢复)检查三种模式、重启和系统切换。
