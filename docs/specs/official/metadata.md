# 媒体元信息

## META-001 提取和展示视频文件元信息

- **入口** 在图库的列表、画廊或图标模式中，右键视频打开「媒体元信息」。面板显示调用时的文件名和读取结果。
- **要求** 按需读取通过 [LIB-001](library.md#lib-001-目录导入与扫描) 安全检查的本地文件，展示视频像素尺寸、时长、标题和作者。作者优先取作者字段，其次取平台实际提供的创建者或艺人字段。分辨率显示视频帧的编码尺寸。字段缺失时显示「未提供」。文件不可用和无法识别元信息分别提示。关闭面板后，读取结果不会写入后续面板或媒体库。
- **范围** 双端使用系统媒体读取器，以实际可识别的格式和容器标签为准。视频可播放时也可能缺少系统可读的元信息，尤其是使用 LibVLC 回退播放的文件。独立音频见 [META-001 后续范围](../spike/metadata.md#meta-001-提取和展示专辑文件元信息)。
- **来源** [0.4.0 视频元信息 #104](https://github.com/AMindFlow/iPreview/issues/104) · [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)
- **验收** 用标注标题和作者的 MP4／MOV、无标签视频、损坏及离线视频分别打开面板。快速关闭并打开另一文件，核对文件名和结果归属。读取前后对比源文件 SHA-256。
