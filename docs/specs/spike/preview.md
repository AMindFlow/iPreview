# 键盘媒体预览后续需求

首版键盘及播放契约见 [PRE-001](../official/preview.md#pre-001-图片与视频预览)。

## PRE-002 常规图片预览与旧版兼容

- **要求** 主图居中、等比适配画布。在有相邻图片的上、下、左、右方向呈现层叠并略模糊的画面，周围用遮罩、模糊或暗化弱化。保留旧版等比适配与原始尺寸切换、首尾导航、触摸滑动和 GIF 动画。覆盖旧版支持的 JPEG（JPG、JPEG）、PNG、WebP、GIF 和 HEIC，Windows HEIC 的首版边界沿用 PRE-001。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)，旧版图库浏览规格
- **验收** 用横图、竖图、GIF 和每种旧格式验证渲染或已明确的系统边界。检查有四向相邻图和位于边界的画面、比例切换、键盘与适用设备的触控，按 Esc 关闭预览后回到入口选中项。

## PRE-003 漫画双页翻页

- **要求** 以书页形式左右同时显示两张图。阅读中可即时切换首页按奇数页或偶数页配对，修正跨页画面的对齐。翻页模拟真实书页效果。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)
- **验收** 用带页码的单数和双数样例验证初始左右页、首页切换后的配对、前后翻页效果和末页。

## PRE-004 视频作品的影碟与图册预览

- **要求** 从作品入口直接预览时以影碟和图册展示作品对象。方向键选择，Space 进入。Esc 在媒体、图册或影碟和作品入口之间逐层返回。在最初进入的层级再次按 Esc 退出。数据来源见 [LIB-006](library.md#lib-006-两种视频作品结构)。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)
- **验收** 用两种作品结构从作品预览进入影片、样张及不同写真集，用 Esc 逐层退回并退出。验证从媒体直接进入时以该层作为退出边界。

## PRE-005 音频专辑封面与 CD 机

- **要求** 预览呈现专辑封面与 CD 机。其他音频交互由代理设计并提交用户审阅后实施。音频组织见 [LIB-007](library.md#lib-007-音频组织)。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)
- **验收** 用户审阅交互设计。实机验证封面与播放状态、已承诺的播放操作和可听输出。

## PRE-006 常见视频格式扩展

- **要求** 系统框架继续承担首版解码、输出与同步。iPreview 通过成熟播放底座扩大常见视频格式覆盖，格式清单依据实际兼容缺口和样例确定。LibVLC 优先验证，libmpv 为备选。可用 ffprobe 核验样例和元信息。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)，[首版解码决定](../official/preview.md#设计决定)
- **验收** 用系统框架无法播放的样例验证双端嵌入、播放、同步和打包。新增生产依赖前提交实测及商用分发方案供确认。随包分发时评估具体 LGPL 构建及插件、传递依赖，核对可替换动态库、许可、对应源码、构建配置与发行地区的编解码专利。
