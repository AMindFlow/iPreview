# 键盘媒体预览后续需求

首版键盘及播放契约见 [PRE-001](../official/preview.md#pre-001-图片与视频预览)。

## PRE-003 漫画双页翻页

- **要求** 以书页形式左右同时显示两张图。阅读中可即时切换首页按奇数页或偶数页配对，修正跨页画面的对齐。翻页模拟真实书页效果。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)
- **验收** 用带页码的单数和双数样例验证初始左右页、首页切换后的配对、前后翻页效果和末页。

## PRE-005 音频专辑封面与 CD 机

- **要求** 预览呈现专辑封面与 CD 机。其他音频交互由代理设计并提交用户审阅后实施。音频组织见 [LIB-007](library.md#lib-007-音频组织)。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)
- **验收** 用户审阅交互设计。实机验证封面与播放状态、已承诺的播放操作和可听输出。

## PRE-006 常见视频格式扩展

本期扫描后缀、回退播放器及验收见[现行 PRE-006](../official/preview.md#pre-006-常见视频格式与本地回退)。后续按真实容器和编码样例确定新增覆盖。

## PRE-008 长按方向键连续切换

- **要求** 沿用[现行 PRE-008](../official/preview.md#pre-008-按原布局预览)的方向和边界。长按方向键连续切换时，图片加载期间显示当前项缩略图或上一张可用画面。单文件解码失败沿用 [PRE-001](../official/preview.md#pre-001-图片与视频预览)的提示和导航行为。
- **来源** [预览体验 #57](https://github.com/AMindFlow/iPreview/issues/57)。
- **验收** 在 macOS、Windows 的列表、画廊和多行图标网格分别长按有效方向键，核对一次按住连续切换多项。用不同尺寸的图片覆盖初次解码与重复切换，逐帧核对画面连续性及松键后的目标。另穿插损坏图片验证错误提示和恢复导航。候选实现及已执行项目见 [PR #67](https://github.com/AMindFlow/iPreview/pull/67)，完整矩阵待实机验证。
