# 键盘媒体预览后续需求

首版键盘及播放契约见 [PRE-001](../official/preview.md#pre-001-图片与视频预览)。

## PRE-002 常规图片预览与旧版兼容

- **边界** 主图适配、弱化相邻图、毛玻璃、GIF 及首版图片格式已交付，见 [PRE-001、009](../official/preview.md)。本条保留旧版原始尺寸、首尾导航、触摸滑动等未完成部分。
- **要求** 保留旧版等比适配与原始尺寸切换、首尾导航和触摸滑动。图片格式及平台解码边界沿用 PRE-001，退出选择遵从 PRE-007，不另设旧版分支规则。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)，旧版图库浏览规格
- **验收** 用横图、竖图、GIF 和每种旧格式验证渲染或已明确的系统边界。检查有四向相邻图和位于边界的画面、比例切换、键盘与适用设备的触控，按 [PRE-007](../official/preview.md#pre-007-space-打开和关闭预览)退出并选中最后查看项。

## PRE-003 漫画双页翻页

- **要求** 以书页形式左右同时显示两张图。阅读中可即时切换首页按奇数页或偶数页配对，修正跨页画面的对齐。翻页模拟真实书页效果。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)
- **验收** 用带页码的单数和双数样例验证初始左右页、首页切换后的配对、前后翻页效果和末页。

## PRE-004 视频作品的影碟与图册预览

- **要求** 从作品入口直接预览时以影碟和图册展示作品对象。方向键选择，Space 进入。Esc 在媒体、图册或影碟和作品入口之间逐层返回。在最初进入的层级再次按 Esc 退出。数据来源见 [LIB-006](library.md#lib-006-两种视频作品结构)。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)
- **验收** 用两种作品结构从作品预览进入影片、样张及不同写真集，用 Esc 逐层退回并退出。验证从媒体直接进入时以该层作为退出边界。

## PRE-005 音频专辑封面与 CD 机

- **要求** 预览呈现专辑封面与 CD 机。其他音频交互由代理设计并提交用户审阅后实施。音频组织见 [LIB-007](library.md#lib-007-音频组织)。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)
- **验收** 用户审阅交互设计。实机验证封面与播放状态、已承诺的播放操作和可听输出。

## PRE-006 常见视频格式扩展

- **要求** 系统框架继续承担首版解码、输出与同步。iPreview 通过成熟播放底座扩大常见视频格式覆盖，格式清单依据实际兼容缺口和样例确定。LibVLC 优先验证，libmpv 为备选。可用 ffprobe 核验样例和元信息。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)，[首版解码决定](../official/preview.md#设计决定)
- **验收** 用系统框架无法播放的样例验证双端嵌入、播放、同步和打包。新增生产依赖前提交实测及商用分发方案供确认。随包分发时评估具体 LGPL 构建及插件、传递依赖，核对可替换动态库、许可、对应源码、构建配置与发行地区的编解码专利。

## PRE-007 退出预览时同步选择

- **要求** 按 [现行 PRE-007](../official/preview.md#pre-007-space-打开和关闭预览)退出时，在图库或搜索结果恢复可交互的同时，选中并聚焦最后查看的媒体。
- **来源** [预览体验 #57](https://github.com/AMindFlow/iPreview/issues/57)。
- **验收** 两端切换多个媒体后，分别用 Space、Esc 和关闭按钮退出。恢复显示时直接核对选中项与焦点，立即按 Space 应重新打开最后查看的媒体。覆盖图库和搜索结果。

## PRE-008 长按方向键连续切换

- **要求** 按 [现行 PRE-008](../official/preview.md#pre-008-按原布局预览)持续切换可解码的媒体时，预览画面保持连续，避免加载中的黑屏闪烁。单文件失败沿用 [PRE-001](../official/preview.md#pre-001-图片与视频预览)的提示和导航行为。
- **来源** [预览体验 #57](https://github.com/AMindFlow/iPreview/issues/57)。
- **验收** 两端在列表、画廊和多行网格长按对应方向键，用不同尺寸图片覆盖初次加载与重复切换，核对画面连续性、选中目标及停止后的最终画面。穿插损坏文件验证失败可见且可继续切换。

## PRE-010 图片文件名复制反馈

- **要求** 图片预览中双击文件名，成功复制后将标题短暂替换为成功文案和图标，再恢复当前文件名。按 [现行 PRE-010](../official/preview.md#pre-010-预览顶栏与媒体适配)复制完整文件名（含扩展名），反馈遵循系统的动画设置。
- **来源** [预览体验 #57](https://github.com/AMindFlow/iPreview/issues/57)。
- **验收** 两端双击含长文件名的图片标题，粘贴核对完整文本，观察成功反馈及标题恢复。反馈期间切到下一张图或退出预览，核对再次进入时的标题和剪贴板内容。
