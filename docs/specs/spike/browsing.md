# 专辑浏览

## BRW-001 图片选中响应

- **要求** 鼠标点击专辑中的图片时及时反馈选中。连续点击时按最后一次选择进入预览，加载缩略图和识别双击期间也能看到单击选中反馈。该条目来自首版使用反馈。
- **来源** [点击图片卡顿 #5](https://github.com/AMindFlow/iPreview/issues/5)
- **验收** 用相同专辑在两端分别记录冷、热缓存下从单击到显示选中态的耗时，比较修复前后。快速切换图片后立即按 Space，应打开最后选中的图片。回归已有双击预览。

## BRW-002 图标、列表和画廊视图

- **要求** 独立预览之前，当前专辑的全部已索引媒体可切换为图标网格、逐行列表或画廊。画廊显示选中媒体的大图与用于浏览的缩略图条。三种布局保持当前集合与选中项，支持键盘和鼠标选择，并按 [PRE-007](preview.md#pre-007-space-打开和关闭预览)进入预览。布局参考 [Finder 视图](https://support.apple.com/en-euro/guide/mac-help/mchldaafb302/mac)。
- **来源** [Finder 式浏览视图 #9](https://github.com/AMindFlow/iPreview/issues/9)
- **验收** 用包含图片和视频的普通专辑、虚拟专辑切换三种视图。核对媒体集合、选中项、画廊随选择更新及从每个视图打开预览。
