# 专辑浏览

## BRW-002 图标、列表和画廊视图

- **要求** 独立预览之前，当前专辑的全部已索引媒体可切换为图标网格、逐行列表或画廊。画廊显示选中媒体的大图与用于浏览的缩略图条。三种布局保持当前集合与选中项，支持键盘和鼠标选择，并按 [PRE-007](../official/preview.md#pre-007-space-打开和关闭预览)进入预览。布局参考 [Finder 视图](https://support.apple.com/en-euro/guide/mac-help/mchldaafb302/mac)。
- **来源** [Finder 式浏览视图 #9](https://github.com/AMindFlow/iPreview/issues/9)
- **验收** 用包含图片和视频的普通专辑、虚拟专辑切换三种视图。核对媒体集合、选中项、画廊随选择更新及从每个视图打开预览。
