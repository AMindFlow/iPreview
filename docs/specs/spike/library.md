# 本地媒体库后续需求

[首版索引契约](../official/library.md)继续适用。旧版行为的追溯基线见[完整需求](../../project/requirements.md#旧版追溯)。

## LIB-003 旧版图库管理

- **要求** 导入时可设置来源显示名，查看候选、扫描进度和结果摘要，包括忽略数量及单项扫描问题。支持监测已登记目录的外部变化，保留离线及失联记录，允许重连来源、清理失效索引或移除登记。媒体名称自然排序，缩略图优先生成当前可见项，缓存位于来源之外且可重建。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)，旧版图库浏览 R-001–R-008 与失联恢复规格
- **验收** 使用合成目录增减文件、模拟路径变更与离线、清空测试缓存，再检查状态、关联、排序和缩略图。在应用移除来源后对比源文件清单。

## LIB-004 多工作区

- **要求** 默认工作区可直接使用。可新建、打开及切换工作区，各工作区独立保存文件夹索引、来源专辑和合集。重启恢复上次使用的工作区。工作区数据独立于应用安装目录和原始媒体。独立窗口及同一工作区的并发保护参照旧版设计。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)，旧版桌面分发与桌面体验补缺规格
- **验收** 用两个工作区对同一来源保存不同组织数据，切换和重启后核对隔离与恢复。若采用独立窗口，验证不同工作区同时使用、同库重复打开行为明确。

## LIB-005 旧库迁移、备份与恢复

- **要求** 保留旧库来源、展示名、相对路径、媒体与专辑逻辑身份、标签、收藏、评分、封面及合集引用和顺序。支持版本化 JSON 备份、用户选择备份目录、组织数据变更后原子更新 latest、运行期间按日保留最近七份快照，并在正常退出前完成待导出项。备份不含媒体字节、缩略图和特定主机绝对根路径。向空工作区恢复前展示预览、显式路径映射、各合集的匹配数和未匹配项，完成后反馈恢复结果。迁移旧 SQLite 与导入旧 JSON 的支持版本分别确认，旧库与媒体保持只读。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)，旧版组织管理与桌面分发规格
- **验收** 从受支持的旧版合成数据库和备份分别迁移到空工作区。覆盖路径变化、失联成员和未匹配项，核对身份映射、组织数据及引用顺序，并对比旧库和媒体快照。

## LIB-007 音频组织

- **要求** 0.4.0 索引本地 MP3、M4A、FLAC、WAV。沿用现有来源层级，以音轨所在文件夹作为音乐专辑。不同文件夹即使包含相同专辑标签仍维持各自归组，视频作品的结构识别只使用视频及图片。
- **要求** 音乐封面优先读取专辑根目录可解码的图片，按文件名自然排序。无可用根目录图片时沿曲目顺序查找可解码的内嵌封面，无图时显示占位。现有显式封面设置由用户控制。媒体只读。播放入口见 [PRE-005](preview.md#pre-005-音频专辑封面与-cd-机)。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)
- **验收** 双端导入作品根目录及父目录。用根目录图与内嵌图不同的专辑、仅内嵌图的专辑、损坏封面与无图专辑核对优先级。升级含合集成员、封面配置和视频作品的 0.3.1 隔离库，确认引用及媒体 ID 保留，对比样例哈希。

## LIB-008 旧版源文件操作

- **要求** 同父目录重命名见 [LIB-011](../official/library.md#lib-011-重命名真实目录和媒体)。保留旧版连续重命名和移入系统回收站的工作流需求，确认、出错和恢复行为待决定。涉及元信息写回另见 [META-002](metadata.md#meta-002-修改并写回实际文件)。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)，旧版安全文件操作与桌面体验补缺规格
- **验收** 先确认允许的操作和恢复方案。若实施，以合成来源验证连续操作、回收和恢复后的索引一致性。
