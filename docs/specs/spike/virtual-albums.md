# 合集与专辑组织后续需求

[首版合集](../official/virtual-albums.md)已具备跨目录引用和持久化顺序。

## ALB-002 旧版标签、收藏、评分与封面

- **要求** 专辑可加标签、筛选，支持全库重命名和移除标签。收藏与 0–5 的半星评分独立，零分和未评分可区分。提供自然排序首张可用图片自动封面、手选封面及 2–4 张有序拼图。媒体暂不可用时回退展示并保留封面配置。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)，旧版图片库组织管理规格
- **验收** 修改标签、收藏、零分和半星评分后重启核对。设定手选及拼图封面，再下线和恢复部分来源，检查显示与配置。

## ALB-003 合集删除

- **边界** 合集内媒体成员在「调整」中拖动排序已由 [ALB-006](../official/virtual-albums.md#alb-006-合集标题与拖动排序)交付；本条余项是合集删除；现有失联引用及占位继续保留。
- **要求** 支持删除合集，显示包含名称、确认及取消的应用内确认界面。取消不写入，确认只删除该合集及其成员关系；失败保留上下文并可重试。跨专辑批量添加见 [ALB-004](../official/virtual-albums.md#alb-004-从来源专辑批量添加媒体)。离线或失联成员有明确占位。删除合集仅移除应用内组织和引用。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)，旧版图片库组织管理规格
- **验收** 用跨来源合集验证取消、确认、删除后返回列表、连续删除／创建及失败恢复；比较源文件快照，其他合集成员和顺序保持不变。
