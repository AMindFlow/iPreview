## META-002 修改并写回实际文件

- **要求** 在应用内修改受支持的字段，并反映到实际媒体文件。可写格式、字段、显式触发、失败语义和恢复方案单独由用户确认。日常导入、索引和预览沿用 [LIB-001](../official/library.md#lib-001-目录导入与扫描) 的只读约束。
- **来源** [总体需求 #3](https://github.com/AMindFlow/iPreview/issues/3)
- **验收** 范围确认后，以合成副本测试修改、独立工具回读、取消及故障恢复，并验证其他字段、媒体内容和未选文件保持一致。
