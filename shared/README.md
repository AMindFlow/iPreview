# 双端数据与验收约定

- 数据库位于本机应用数据目录。从 `PRAGMA user_version = 0` 按版本在事务中依次执行 [初始结构](migrations/001-initial.sql)、[重命名恢复记录](migrations/002-pending-rename.sql)、[来源专辑组织](migrations/003-album-organization.sql)、[视频作品索引](migrations/004-video-works.sql)及[来源与媒体身份序列](migrations/005-source-media-identities.sql)。每次打开连接后启用外键。
- `sources.path` 为平台原生绝对路径。`media.relative_path` 以 `/` 存储相对于来源的文件路径。重扫事务保留同一路径的媒体行 ID，消失的媒体标记不可用。根目录不可访问时仅标记来源离线，重新联机扫描后恢复。合集关联媒体 ID，通过 `position` 排序。删除来源再导入相同目录时分配新的来源和媒体 ID，旧引用无法关联到新索引。
- 普通来源导入探测读取直属普通文件及两种约定深度。识别作品时额外读取规定的样张及写真集目录。单创作者命中深度 2，多创作者命中深度 3。两者都命中时展示两种选择。只有未命中这两种结构时才使用直属媒体。忽略隐藏项、符号链接与 Windows 重解析点。
- 扩展名不区分大小写。图片为 jpg、jpeg、png、webp、gif、heic，视频为 mp4、mov。缩略图与播放只读访问源路径。明确确认的本地重命名见 [LIB-011](../docs/specs/official/library.md#lib-011-重命名真实目录和媒体)。
- 路径各级目录名（含选择的根目录名）和文件名可独立匹配。结果显示匹配项及路径。精确匹配按 NFKC、不区分大小写，目录匹配完整名称。文件可省略最后一个后缀。查询以支持的媒体后缀结尾时匹配完整文件名，其余查询保留名称中的点号。模糊匹配按完全、前缀、子串、全拼、首字母、拼写容错排序。同等级按自然顺序，拼写容错至少三个字符。拼音保留 `lü` → `lv`。搜索范围都关闭时显示空结果。
- 浏览、预览及搜索的键盘规则以 [PRE-007–011](../docs/specs/official/preview.md)和 [SRCH-002](../docs/specs/official/search.md#srch-002-当前范围和全局搜索)为准。退出同步最后查看项与焦点，停止播放；不在共享数据契约重复定义平台交互。

## 来源专辑组织

[ALB-002](../docs/specs/spike/virtual-albums.md#alb-002-旧版标签收藏评分与封面) 的组织数据按需存入 `source_album_organization`。键为来源 ID 与以 `/` 分隔的相对专辑目录，直属来源使用空路径。路径沿用媒体索引中的实际拼写。通过应用重命名专辑或其上级目录时，其组织路径与媒体索引在同一事务移动。缺少组织行时默认未收藏、未评分、无标签、自动封面。虚拟合集继续使用 `albums` 与 `album_media`。

- `rating_half` 以整数 0–10 表示 0–5 星，`NULL` 表示未评分。收藏独立存储。
- `tags` 保存全库标签及其唯一规范名称。显示名称做 NFKC、去除首尾空白并折叠连续空白。唯一键先做规范分解，再用与区域无关的小写转换，最后规范合成。同名规范键冲突时保留现有标签。重命名更新标签行且保留关联，删除标签时移除其关联。搜索通过 `source_album_tags` 关联至来源专辑。
- `source_album_cover_media` 按从零开始的连续位置保存有序媒体 ID。零张表示自动，一张表示手选，两至四张表示拼图。写入时须确认成员属于同一来源专辑且为图片，整组在单一事务替换。源离线或所配置的任一图片暂不可用时，显示自然排序首张可用图片或来源占位，保留配置待恢复。
- 双端目录 API 用 `SourceAlbumKey` 定位专辑。标签列表、规范名称和按标签 ID 查询专辑的接口供 SRCH-003 复用。按专辑读取同时给出已配置和按当前索引可用状态计算的有效封面 ID。

## 视频作品

`video_works` 以主视频媒体 ID 标识作品，保存完整或简化结构。`video_work_images` 保存随目录扫描的样张、写真集封面、照片及组内次序。作品路径根据主视频路径和结构派生。媒体路径重命名后沿用相同 ID。在线扫描一并更新媒体索引和归组，离线保留，删除对应媒体时由外键级联清理。
